PRJ.01

Smart Campus Lost & Found System

Centralized recovery platform with AI-assisted item matching

React.js TypeScript NestJS PostgreSQL Prisma Redis Socket.IO Docker

Campus lost-item reporting was scattered across notice boards and word of mouth, with no way to verify a claim. Built a role-based platform for students, faculty, security, and admins that scores potential matches by keyword similarity, category, location, and date.

  • Role-based access control across four distinct user types with separate permission boundaries
  • Automated match-scoring engine combining keyword, category, location, and time-window signals
  • Real-time claim verification workflow using Socket.IO, with an admin analytics dashboard for recovery-rate tracking
  • JWT-secured REST API layer with Redis caching, containerized and deployed via Docker + Vercel
